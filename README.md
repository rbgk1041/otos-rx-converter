# OTOS 도수보안경 데이터 변환기

기능 요구사항을 기준으로 새로 작성한 독립 웹앱입니다. 타인의 Lovable 프로젝트 코드나 배포 번들을 포함하지 않습니다. ExcelJS 4.4.0(MIT)만 vendor에 포함합니다.

## 실행
Node.js 22로 `npm test`. 로컬 확인은 `npm start` 후 http://localhost:8080 에 접속합니다. 의존성 설치나 API 키가 필요 없습니다.

## 입력
XLSX 파일에 `보안경명단`(4행 제목, 5행 데이터), `시력데이터`(3행 제목, 4행 데이터)를 함께 넣습니다. 앱에서 가상 데이터 샘플 양식을 다운로드할 수 있습니다. 구형 XLS는 XLSX로 변환해야 합니다.
센터+팀+성명(공백 제거)으로 매칭하며 사번은 출력에만 사용합니다. 우·좌안은 OD/OS 또는 R/L 등으로 명시하며 같은 사람의 두 행을 연속 입력합니다. 각 사람의 첫 행에는 이름·센터·팀이 필요합니다. 빈 행은 사람 경계를 끊습니다.

## 검토
신청 중복과 시력 중복은 최종 출력에서 제외하고 별도 목록에 표시합니다. 좌우 PD를 합산하며 합계 90 초과 및 한쪽 누락 등은 확인 대상으로 분류합니다. ADD는 숫자 값으로 비교합니다. 값 수정 시 숫자·축 범위·누락 검사를 다시 수행합니다. 도수의 임상적 적합성을 판단하는 앱은 아닙니다.
원본 안내 검토 완료는 원본 차이에 대한 확인이며 입력값 검증을 해제하지 않습니다. 강제포함은 경고 행을 최종 출력에 포함하므로 원본 확인 후 사용하세요. 최종 출력 파일에는 오류사유 열이 없으며 매칭 완료/값 확인 다운로드에는 포함됩니다.

## GitHub Pages 배포
1. 새 저장소를 만들고 이 폴더의 내용(숨김 .github 포함)을 저장소 루트에 올립니다. main 브랜치를 사용합니다.
2. Settings → Pages → Source에서 GitHub Actions를 선택합니다.
3. Actions → Test and deploy to GitHub Pages → Run workflow를 실행합니다.
4. 성공한 배포의 URL로 접속합니다. 후속 main 푸시는 자동 테스트 후 배포됩니다.
GitHub 계정 요금제와 저장소 공개 범위에 따라 Pages 제공 조건이 다를 수 있습니다. 저장소나 사이트를 공개하기 전 공개 범위를 직접 확인하세요.

## 개인정보와 제한
엑셀을 읽고 만드는 처리는 브라우저 메모리에서 수행합니다. 원본 파일을 서버로 전송하거나 저장하지 않습니다. 페이지 새로고침 시 편집 내용은 사라집니다. 실제 업무 파일 검증은 아직 수행하지 않았습니다. 모든 데이터는 출력 전에 원본과 확인하세요.

## 검증
자동 테스트 10개 통과: PD 합산, ID 앞자리 0 유지, 신청/시력 중복 제외, ADD 숫자 동등성, PD 상한 경고, 수정 후 검증, 다음 사람과 우좌안 분리, 역순 눈 데이터, 필수 헤더, XLSX 읽기·쓰기. 초기 화면 브라우저 확인 완료. 실제 사용자 파일 및 전체 브라우저 업로드/다운로드 흐름은 미검증입니다.
